\section{Introduction}
% ══════════════════════════════════════════════════════════════════════════

We study a reinforcement learning problem in which a delivery robot must visit
$K$ landmarks on an $N \times N$ grid in a \emph{hidden} order that is
randomised at every episode. The agent receives only binary feedback (correct /
wrong) after each visit attempt, and must therefore \emph{infer} the ordering
from its interaction history. This makes the task a Partially Observable Markov
Decision Process (POMDP), where the optimal policy is inherently non-Markov in
the observation and requires memory.

The problem is inspired by real-world scenarios such as multi-stop delivery
routing where the priority of stops is unknown to the driver and can only be
discovered on arrival. It is not a Travelling Salesman Problem: the order is
fixed but unknown, and the agent must trade off \emph{information gain} against
\emph{travel cost}.

We implement the environment as a Gymnasium-compatible Python module and train
agents using the Stable Baselines 3 ecosystem. Our key contribution is a
\textbf{systematic investigation of why standard RL algorithms fail on this
POMDP} and the design choices needed to enable successful learning:
reward shaping, penalty tuning, and problem scaling.

% ══════════════════════════════════════════════════════════════════════════
\section{Problem Formulation}
% ══════════════════════════════════════════════════════════════════════════

\subsection{POMDP Specification}

We formalise the problem as a POMDP tuple $(\mathcal{S}, \mathcal{A},
\mathcal{O}, T, R, O, \gamma)$:

\paragraph{Hidden state $s_t$.}
\[
  s_t = \bigl(\, p_t,\; \{\ell_i\}_{i=1}^K,\; \pi,\; k_t,\; t \,\bigr)
\]
where $p_t \in \{0,\ldots,N{-}1\}^2$ is the robot position, $\ell_i$ are
landmark positions, $\pi \in S_K$ is the hidden visiting permutation, $k_t$ is
the number of correct visits so far, and $t$ is the step counter.

\paragraph{Observation $o_t$.}
The agent observes:
\begin{itemize}[nosep]
  \item A $5\times5$ ego-centric view (one-hot encoding over
        $\{\text{empty},\, \text{landmark}_1,\ldots,\text{landmark}_K,\, \text{wall}\}$).
  \item A history vector $h_t \in \{-1,\,0,\,+1\}^K$: $-1$ = tried \& rejected,
        $0$ = unknown, $+1$ = confirmed correct.
  \item Progress $k_t / K$ and normalised remaining steps $(T - t)/T$.
\end{itemize}
Crucially, the permutation $\pi$ is \textbf{never} revealed.

\paragraph{Action space.}
$\mathcal{A} = \{\text{Up, Down, Left, Right, Visit}\}$, $|\mathcal{A}|=5$.

\paragraph{Reward structure.}

\begin{table}[H]
\centering
\begin{tabular}{lr}
\toprule
\textbf{Event} & \textbf{Reward} \\
\midrule
Per-step cost (any action)           & $-0.01$ \\
Wall bump                            & $-0.05$ \\
Visit on empty cell                  & $-0.05$ \\
Correct landmark visit               & $+1.00$ \\
Wrong landmark visit                 & $-p$ (configurable) \\
Completing full sequence ($k=K$)     & $+5.00$ \\
Timeout ($t = T$)                    & $-1.00$ \\
\bottomrule
\end{tabular}
\caption{Reward function design. The wrong-visit penalty $p$ is a key hyperparameter investigated in this work (default $p=0.5$).}
\label{tab:rewards}
\end{table}

\subsection{Why This Is Novel}

\begin{itemize}[nosep]
  \item Standard gridworlds expose the goal; here the goal-ordering is hidden.
  \item Unlike TSP, the order is fixed but unknown---pure shortest-path
        heuristics fail.
  \item The optimal policy requires \emph{sequential hypothesis testing}:
        the agent must actively explore to narrow down the $K!$ possible
        orderings.
  \item The history vector $h_t$ is a sufficient statistic for belief
        tracking, but learning to \emph{use} it is non-trivial.
\end{itemize}

\paragraph{Reward shaping.}
We implement a potential-based shaping term (Ng et al., 1999):
\[
  F(s, s') = \gamma \, \Phi(s') - \Phi(s), \qquad
  \Phi(s) = -\frac{d_{\min}(p, \text{plausible landmarks})}
                   {2(N-1)}
\]
where $d_{\min}$ is Manhattan distance to the nearest landmark with $h_i = 0$ (untried). This gives a continuous positive gradient toward landmarks without changing the optimal policy in theory.

\section{Environment Implementation}
% ══════════════════════════════════════════════════════════════════════════

The environment is implemented as a Gymnasium \texttt{Env} subclass
(\texttt{env.py}) using the Stable Baselines 3 framework for all algorithm implementations. Key design decisions:

\begin{enumerate}[nosep]
  \item \textbf{Dict observation space:} Separate ego-view, history,
        progress, and time budget into distinct keys for SB3's
        \texttt{MultiInputPolicy}.
  \item \textbf{Deterministic dynamics:} Stochasticity comes only from the
        hidden permutation and initial placement.
  \item \textbf{Configurable difficulty:} Grid size ($N$), number of landmarks
        ($K$), view size, wrong-visit penalty ($p$), and reward shaping
        are all adjustable.
  \item \textbf{Headless rendering:} Pygame-based renderer (\texttt{render.py})
        produces RGB frames for video recording.
\end{enumerate}

% ══════════════════════════════════════════════════════════════════════════
\section{Algorithms}
% ══════════════════════════════════════════════════════════════════════════

All algorithms are from the Stable Baselines 3 (SB3) ecosystem:

\begin{itemize}[nosep]
  \item \textbf{PPO:} Feed-forward \texttt{MultiInputPolicy} with $[256,256]$ MLPs. 16 parallel envs.
  \item \textbf{Recurrent PPO (LSTM):} \texttt{MultiInputLstmPolicy} from \texttt{sb3-contrib} with 128-unit LSTM + $[128,128]$ MLPs. The LSTM maintains internal state across timesteps, enabling belief tracking.
  \item \textbf{DQN:} $[256,256]$ MLP with experience replay (200k buffer), $\varepsilon$-greedy exploration.
  \item \textbf{QR-DQN:} Distributional DQN with 51 quantiles.
\end{itemize}

\section{Experimental Journey: From Failure to Success}
% ══════════════════════════════════════════════════════════════════════════

This section documents our iterative debugging process, which is central to
understanding how to solve POMDPs with deep RL.

% ── Phase 1 ───────────────────────────────────────────────────────────────
\subsection{Phase 1: Large Grid Baseline ($12\times12$, $K\!=\!4$, $p\!=\!0.5$)}

\paragraph{Setup.} Our initial configuration followed standard practice:
$12\times12$ grid, 4 landmarks ($4!=24$ orderings), $5\times5$ ego-view,
wrong-visit penalty $p=0.5$, no reward shaping. We trained PPO, DQN, and
RecurrentPPO for 5M steps each.

\paragraph{Results.}

\begin{table}[H]
\centering
\begin{tabular}{lcccc}
\toprule
\textbf{Algorithm} & \textbf{Reward} & \textbf{Success Rate}
  & \textbf{Wrong Visits} & \textbf{Ep.\ Length} \\
\midrule
Random baseline    & $-5.95 \pm 0.94$  & 0.0\%  & 0.99  & 200.0 \\
PPO (3 seeds)      & $-3.00 \pm 0.00$  & 0.0\%  & 0.00  & 200.0 \\
DQN (seed 0)       & $-3.97 \pm 7.67$  & 0.0\%  & 1.73  & 200.0 \\
RecurrentPPO       & $-3.00 \pm 0.00$  & 0.0\%  & 0.00  & 200.0 \\
\bottomrule
\end{tabular}
\caption{Phase 1: All algorithms fail on the large grid. 200 eval episodes.}
\label{tab:phase1}
\end{table}

\paragraph{Analysis: The ``Never Visit'' Local Optimum.}
Every algorithm converged to a policy that \emph{never executes the Visit
action}. The reward decomposition reveals why:
\[
  \underbrace{200 \times (-0.01)}_{\text{step cost}} + \underbrace{(-1.0)}_{\text{timeout}} = -3.0
\]
Meanwhile, each exploratory visit attempt has \textbf{negative expected value}:
\[
  \mathbb{E}[\text{single visit}] = \frac{1}{4} \times (+1.0) + \frac{3}{4} \times (-0.5) = -0.125
\]
The agent rationally concludes that \emph{doing nothing} ($-3.0$) beats
\emph{trying} (expected $< -3.0$). This is a fundamental exploration problem:
the large positive reward from completing the sequence ($+8.0$) is too
unlikely to discover through random exploration.

\paragraph{Additional factors.}
\begin{itemize}[nosep]
  \item \textbf{Low visibility:} $5\times5$ view covers only $25/144 = 17\%$ of
        the $12\times12$ grid. Landmarks are usually invisible.
  \item \textbf{High combinatorial complexity:} $4! = 24$ orderings require
        extensive exploration to disambiguate.
  \item DQN performs worst ($-3.97$, 1.73 wrong visits) because $\varepsilon$-greedy
        forces random Visit actions, incurring penalties.
\end{itemize}

% ── Phase 2 ───────────────────────────────────────────────────────────────
\subsection{Phase 2: Adding Reward Shaping ($12\times12$, $K\!=\!4$, $p\!=\!0.5$, shaped)}

\paragraph{Hypothesis.} The agent cannot discover landmarks because it has no
gradient signal pointing toward them. Potential-based reward shaping should
guide navigation without changing the optimal policy.

\paragraph{Results.} RecurrentPPO with shaping reached train reward $-2.69$
at 2M steps (vs.\ $-3.03$ without shaping). The improvement indicates the
agent learned to \textbf{approach landmarks}, but eval reward remained $-3.00$
with 0\% success---the best model saved by EvalCallback still corresponded to
the ``never visit'' strategy because eval uses unmodified rewards.

\paragraph{Takeaway.} Reward shaping helps navigation but is insufficient
alone: the agent approaches landmarks but still does not dare to visit them.

% ── Phase 3 ───────────────────────────────────────────────────────────────
\subsection{Phase 3: Reducing Wrong-Visit Penalty ($12\times12$, $K\!=\!4$, $p\!=\!0.1$, shaped)}

\paragraph{Hypothesis.} With $p=0.1$, a single visit attempt has positive
expected value:
\[
  \mathbb{E}[\text{single visit}] = \frac{1}{4} \times (+1.0) + \frac{3}{4} \times (-0.1) = +0.175 > 0
\]
This should incentivise exploration.

\paragraph{Results.} RecurrentPPO with shaping + low penalty reached $-2.62$
at 1.3M steps, slightly better than Phase 2 at the same stage. However,
eval success rate remained 0\%---the $12\times12$ grid is still too large for
the agent to reliably find and visit landmarks.

\paragraph{Takeaway.} Lowering penalty makes exploration rational in
expectation, but spatial exploration on a large grid with limited vision
remains the bottleneck.

% ── Phase 4 ───────────────────────────────────────────────────────────────
\subsection{Phase 4: Scaling Down ($6\times6$, $K\!=\!3$, $p\!=\!0.1$, shaped) --- Breakthrough}

\paragraph{Hypothesis.} The core POMDP challenge (inferring hidden order) is
orthogonal to the spatial navigation challenge. By reducing the grid to
$6\times6$ (view coverage: $25/36 = 69\%$), landmarks to 3 (only $3!=6$
orderings), and episode length to 100 steps, we isolate the POMDP reasoning
from spatial difficulty.

\paragraph{Results (3 seeds, 2M steps each, 200 eval episodes per seed).}

\begin{table}[H]
\centering
\begin{tabular}{lcccc}
\toprule
\textbf{Agent} & \textbf{Reward (mean$\pm$std)} & \textbf{Success Rate}
  & \textbf{Best Episode} \\
\midrule
Random baseline (6$\times$6, $K$=3) & $\sim -3.0$ & 0.0\% & --- \\
RecurrentPPO seed 0  & $+6.09 \pm 3.04$ & \textbf{87.5\%} & $+7.91$ \\
RecurrentPPO seed 1  & $-2.00 \pm 0.11$ & 0.0\% & $-1.10$ \\
RecurrentPPO seed 2  & $+4.79 \pm 4.59$ & \textbf{78.5\%} & $+7.89$ \\
\bottomrule
\end{tabular}
\caption{Phase 4: Small grid results across 3 seeds. Seeds 0 and 2 solve the task; seed 1 fails.}
\label{tab:phase4}
\end{table}

\paragraph{Why seed 1 failed: the exploration lottery.}
Seed 1 converged to the same ``never visit'' strategy ($-2.0$ reward) as the
large-grid experiments. The root cause is \textbf{early exploration
stochasticity}: the initial random weights and early trajectory samples
determine whether the agent discovers a correct visit within the first
$\sim$100k steps. Seeds 0 and 2 happened to stumble upon a correct visit
early, providing a positive reward signal ($+1.0$) that the LSTM could
latch onto and generalise. Seed 1 never received this ``lucky'' signal and
remained stuck in the local optimum.

This is a well-known phenomenon in RL: \textbf{the same hyperparameters can
yield vastly different outcomes depending on the random seed}. With 3 seeds,
we observe a 67\% success rate at the seed level (2 out of 3 seeds solve the
task), suggesting the algorithm is effective but not fully robust. Strategies
to improve seed robustness include:
\begin{itemize}[nosep]
  \item Higher entropy coefficient to encourage exploration.
  \item Curriculum learning: start with $K=2$ landmarks and increase.
  \item Longer training with exploration bonuses (e.g., intrinsic curiosity).
\end{itemize}

\paragraph{Training dynamics (seed 0).}
The train reward trajectory tells a clear story of learning progression:
\begin{itemize}[nosep]
  \item \textbf{0--50k steps:} Random exploration, reward $\sim -3.15$.
  \item \textbf{50k--200k:} Agent learns navigation toward landmarks
        ($-3.15 \to -2.59$), driven by reward shaping.
  \item \textbf{200k--800k:} Agent begins attempting visits, reward improves
        through correct deliveries ($-2.59 \to -1.87$).
  \item \textbf{800k--1.5M:} LSTM learns to track history and plan
        multi-step visit sequences ($-1.87 \to -1.35$ train).
  \item \textbf{1.5M--2M:} Rapid convergence to near-optimal policy.
        Eval reward peaks at $+6.63$, train reward reaches $+6.35$.
\end{itemize}

\paragraph{Best episode reward: $+7.91$.} This is close to the theoretical
maximum of $3 \times 1.0 + 5.0 - \text{steps} \times 0.01 = +7.0 \sim +7.9$,
confirming the agent learned the near-optimal strategy.

\subsection{The Three Barriers to POMDP Learning}

Our experiments reveal three independent barriers that must all be overcome:

\begin{enumerate}
  \item \textbf{Exploration incentive:} The expected reward of a single
        visit attempt must be positive ($p < 1/K \times r_{\text{correct}} /
        (1 - 1/K)$). With $K=4$ and $r_{\text{correct}}=1.0$, this requires
        $p < 0.33$. Our original $p=0.5$ violated this, making
        ``never visit'' the rational policy.

  \item \textbf{Spatial coverage:} The agent's ego-view must cover enough of
        the grid that landmarks are frequently visible. On a $12\times12$ grid
        with $5\times5$ view (17\% coverage), the agent spends most of its
        time navigating blind. On $6\times6$ (69\% coverage), landmarks are
        almost always visible.

  \item \textbf{Memory capacity:} The policy must maintain beliefs over
        $K!$ orderings. RecurrentPPO (LSTM) succeeds where PPO (MLP) fails,
        even with the hand-crafted history vector---confirming that
        \textbf{learned memory} is essential for this POMDP.
\end{enumerate}

\subsection{Feed-Forward vs.\ Recurrent: A POMDP Litmus Test}

The stark difference between PPO (0\% success, all configurations) and
RecurrentPPO (87.5\% on the feasible configuration) demonstrates that this
environment is a \textbf{genuine POMDP} that cannot be solved by Markov
approximations. The history vector $h_t$ is a sufficient statistic in
theory, but the MLP-based PPO cannot learn to use it effectively---the LSTM
discovers its own internal representation that better supports sequential
decision-making.

\subsection{Scaling Considerations}

Our results suggest that the $12\times12$, $K=4$ configuration is solvable
in principle but requires:
\begin{itemize}[nosep]
  \item Larger view size (e.g., $7\times7$ or $9\times9$) or global
        position information in the observation.
  \item Longer training (possibly $>$50M steps) with curriculum learning.
  \item Larger LSTM capacity and possibly attention-based architectures.
\end{itemize}

\subsection{Limitations}

\begin{itemize}[nosep]
  \item We only achieved success on the $6\times6$ configuration; the
        $12\times12$ version remains unsolved.
  \item The EvalCallback saves models based on unmodified reward, so
        shaped training + unmodified eval creates a mismatch where
        ``never visit'' appears optimal to the callback.
  \item Only 3 seeds were run; larger seed counts would give tighter
        confidence intervals.
\end{itemize}

\section{Conclusion}
% ══════════════════════════════════════════════════════════════════════════

We presented Sequential Multi-Target Delivery, a novel POMDP environment where
a robot must infer a hidden visiting order through trial-and-error. Through
systematic experimentation, we identified three barriers to learning---exploration
incentive, spatial coverage, and memory capacity---and showed that all three
must be addressed simultaneously.

Our main findings:
\begin{enumerate}[nosep]
  \item \textbf{Feed-forward methods fail:} PPO and DQN converge to a
        ``never visit'' avoidance strategy ($-3.0$ reward, 0\% success)
        across all configurations tested.
  \item \textbf{Reward shaping + penalty tuning are necessary but not
        sufficient:} They improve training reward but do not achieve
        task completion on a large grid.
  \item \textbf{RecurrentPPO succeeds} when the problem is scaled to a
        feasible difficulty: $6\times6$ grid, $K=3$ landmarks, with reward
        shaping and low wrong-visit penalty. It achieves \textbf{87.5\%
        success rate} (seed 0) and near-optimal reward ($+6.09$, best $+7.91$).
  \item \textbf{Seed sensitivity matters:} Out of 3 random seeds, 2 solve the
        task (87.5\% and 78.5\% success) while 1 fails entirely (0\%).
        This highlights the role of early exploration luck in RL and
        motivates future work on exploration robustness.
  \item \textbf{The iterative debugging process}---from total failure to
        87.5\% success---demonstrates the importance of systematic ablation
        in RL research.
\end{enumerate}
